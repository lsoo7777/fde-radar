Discovery-to-brief in 15 minutes

5 steps: Record the call with an approved notetaker (e.g. Fathom, Granola).

DiscoveryFDE Radar2026-10-16
{ } details
type Workflow = {
  category: "Discovery";
  steps: 5;
}
1. Record the call with an approved notetaker (e.g. Fathom, Granola).
2. Paste the transcript into your AI tool with the 'deal summary' prompt.
3. Ask it to list every assumption not stated by the customer.
4. Fix gaps, then generate a 5-bullet brief for your AE and a follow-up email draft.
5. Log the brief in CRM and set next-step dates.

Agent POC with evals

5 steps: Pick one narrow task and collect 20–50 real example inputs (with permission).

POCFDE Radar2026-10-16
{ } details
type Workflow = {
  category: "POC";
  steps: 5;
}
1. Pick one narrow task and collect 20–50 real example inputs (with permission).
2. Build the first version with an agent framework (e.g. LangGraph, OpenAI Agents SDK).
3. Write expected outputs and run them through an eval tool (e.g. promptfoo, DeepEval).
4. Trace failures with an observability tool (e.g. Langfuse, LangSmith).
5. Report pass rate against the agreed criteria, not vibes.

SecurityFDE Radar2026-10-16
{ } details
type Workflow = {
  category: "Security";
  steps: 5;
}

2. Prompt the AI to answer only from those docs and mark gaps NEEDS REVIEW.
3. Route NEEDS REVIEW items to security/legal owners.
4. Store final answers in your RFP tool (e.g. Loopio, Responsive) for reuse.
