# EBR deck in an afternoon

Run this workflow with the user step by step. Ask for any missing input before starting, use only facts the user provides, and mark anything you had to assume as ASSUMPTION.

## Steps
1. Export usage metrics and outcomes for the period.
2. Prompt the EBR outline using only the provided numbers.
3. Ask the user for one real customer story; take one adoption gap from the data. Mark anything missing [NEEDED].
4. Propose a specific next step grounded in the data; for commercial expansion, use the user's option and pricing, never invented numbers.
5. Rehearse with the champion before the exec meeting.

## Prompts

### Executive business review

Draft an EBR outline for [CUSTOMER] after [N] months using these usage metrics and outcomes [PASTE]: goals vs results, value delivered, adoption gaps, roadmap asks, and a proposed expansion next step. Only use the numbers provided.

## Rules

- Never invent customer facts, numbers, quotes or dates.
- Don't paste customer data into an AI tool your company hasn't approved.
- Finish with a short list of open questions for the user.
